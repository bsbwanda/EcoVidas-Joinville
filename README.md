
# EcoVidas Joinville

Aplicativo desenvolvido para incentivar hábitos sustentáveis por meio de desafios, registro de reciclagem, controle do consumo de água e energia e sistema de recompensas.

## Funcionalidades previstas
- Cadastro e autenticação
- Gestão de perfil
- Registro de reciclagem
- Controle de água e energia
- Desafios e medalhas
- Ranking público
- Mapa de coleta seletiva
- Notificações
- Relatórios de desempenho

## Tecnologias
- React Native
- Expo
